# Задания практической работы

## Задание 1

Вычислить синус угла, заданного пользователем в градусах.

Для перевода градусов в радианы используется формула:

```c
rad = gr * M_PI / 180;
```

Синус вычисляется функцией:

```c
sin(rad)
```

Контрольные значения:

- 30° → 0.500000
- 60° → 0.866025
- 90° → 1.000000

## Задание 2

Пользователь вводит значение `x`.

Для вычисления используются математические функции стандартной библиотеки `math.h`:

```c
a = log(fabs(-k * x));
b = exp(2 * x) + a * x;
y = x * pow(a, 3) + pow(b, 2);
```

Константа:

```c
k = -4
```

## Задание 3

Используются целые части значений, полученных в задании 2:

```c
A = (int)a;
B = (int)b;
C = (int)y;
```

Проверяются два условия:

1. Только одно из чисел `A` и `B` является четным.
2. Каждое из чисел `A`, `B`, `C` кратно трем.

Результат условия выводится в виде:

```text
1 - да
0 - нет
```

# Домашнее задание

## Вариант 15

### Условие задачи

Вычислить значение выражения:

```text
      x^(y+1) + e^(y-1)
h = --------------------- * (1 + |y - x|)
      1 + x|y - tg(z)|

    |y - x|^2   |y - x|^3
  + --------- - ---------
        2           3
```

Контрольные данные:

- `x = 2.444`
- `y = 0.869 * 10^-2`
- `z = -0.13 * 10^3`

Контрольный результат:

```text
h = -0.49871
```

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Задать постоянные значения:
   - `y = 0.869e-2`
   - `z = -0.13e3`
3. Ввести значение `x`.
4. Вычислить:
   - `pow(x, y + 1)` — значение `x^(y+1)`;
   - `exp(y - 1)` — значение `e^(y-1)`;
   - `tan(z)` — тангенс `z`;
   - `fabs(y - tan(z))` — модуль `y - tg(z)`;
   - `fabs(y - x)` — модуль `y - x`.
5. Вычислить значение функции `h`.
6. Вывести значения `x`, `y`, `z` и результат `h`.
7. **Конец**

## 2. Реализация программы

Домашнее задание реализовано на языке **C** в файле `domashka.c`.

Основное вычисление:

```c
h = (pow(x, y + 1) + exp(y - 1)) /
    (1 + x * fabs(y - tan(z))) *
    (1 + fabs(y - x))
    + pow(fabs(y - x), 2) / 2
    - pow(fabs(y - x), 3) / 3;
```

Для математических функций подключается библиотека:

```c
#include <math.h>
```
